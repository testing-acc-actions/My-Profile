# Shaik Mujahid Atel — Personal Portfolio

A responsive dark-themed portfolio for AWS Cloud and DevOps opportunities.

## Built with
- Semantic HTML, CSS and vanilla JavaScript
- Responsive layouts and accessible navigation
- Scroll reveal effects with reduced-motion support
- GitHub Actions deployment to GitHub Pages

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. Push to `main` or run the workflow manually from the Actions tab.
4. The site will be published at: https://testing-acc-actions.github.io/My-Profile/

## Content accuracy
Experience, certifications, education and recognition are based on the supplied resume. Project cards link to public repositories and distinguish in-progress work from documented projects.

## Update your details
Edit `index.html` for content and `style.css` for visual styling. Contact links are mailto, LinkedIn and GitHub.
